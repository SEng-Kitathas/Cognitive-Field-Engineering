# Engineering Decision Ledger

## D-001 — CFE claim ceiling
**Decision:** use `core observation established; mechanism unresolved` as the active scientific posture.
**Reason:** six paired seeds show family-dependent sign-changing effects; predictive mechanism not yet earned.
**Reversal condition:** a preregistered mechanism campaign predicts family behavior prospectively and survives hostile replication.

## D-002 — Treat the -71 as primary causal pressure
**Decision:** bounded-transport harm is a mechanism probe, not an inconvenient side result.
**Reason:** CONTROL outperforming TREATMENT by 71 discordant cases disproves a simple globally-better-treatment story.

## D-003 — No more v1.0 adaptive extension
**Decision:** v1.0 is closed after the preregistered six-seed screen.
**Reason:** further seed addition would be post-outcome adaptation.

## D-004 — K1/K2/K4 candidate is parked, not discarded
**Decision:** keep the technically qualified concentration-dose candidate, but do not run it before cheaper mechanism discriminators.
**Reason:** concentration sweep can produce an interpretable-looking curve while leaving interference/wrong-neighborhood/horizon confounded.

## D-005 — Mechanism tournament non-discrimination is a negative result
**Decision:** if preregistered discriminators fail, disposition is `EVIDENCE_AGAINST_CURRENT_MECHANISTIC_PICTURE`.
**Forbidden rescue:** `probably a combination`, `needs more tuning`, or equivalent without a new evidence-derived model.

## D-006 — Identifying neighborhood standard
**Decision:** a neighborhood is not qualified merely because it is a complete truth table; it must eliminate plausible rival rules on learner-visible support.
**Reason:** mature CFE lineage says `RICH_CONTRAST_SET != IDENTIFYING_CONTRAST_SET`.

## D-007 — Bounded transport requires a reconstituted-basis discriminator
**Decision:** test rearrangement of the same cells separately from a genuinely different basis that varies causal operands and includes negative slack / farther overflow.
**Reason:** same-cell rearrangement can test interference; only new basis constitution can separate wrong-neighborhood from interference.

## D-008 — Update-field is a first-class training object
**Decision:** characterize the 32-exposure accumulation window, not only individual sequences or global corpus.
**Reason:** microbatch 1 + grad accumulation 8 means optimizer integration happens across 8 four-cell sequences.

## D-009 — Explicit binding != latent relation transfer
**Decision:** do not claim latent archetype installation from evaluations that explicitly state the rule/policy.
**Reason:** historical CFE v0.4 separated those tiers; v1.0 evaluator partially collapsed them.

## D-010 — GitHub continuity is project policy
**Decision:** every material turn updates continuity and creates/pushes a Git commit when authenticated remote access is available; push success requires remote-head readback.
**Reason:** prevent continuity loss and repeated backward reconstruction.

## D-011 — Thin normal clone
**Decision:** code, continuity, doctrine, small state and reproducibility artifacts live in Git; raw reincarnation packages/models/checkpoints live in opt-in release/archive surfaces.
**Reason:** installing/pulling runtime must not force-download the R&D warehouse.

## D-012 — R3.1 is the active stable process SOP for CFE
**Decision:** use R3.1 process layer; do not reintroduce predecessor mandatory method-stack behavior.
**Critical corrections:** `METHOD_STACK_REFERENCE != MANDATORY_PIPELINE`, `ROLE_LABEL != AUTHORITY`, `MODE_LABEL != MUTATION_PERMISSION`.
