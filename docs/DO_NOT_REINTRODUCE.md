# Do Not Reintroduce

This file is intentionally blunt. These are regressions, invalidated assumptions, or dangerous shortcuts.

## Scientific regressions
- Do **not** reframe v1.0 as a clean positive CFE win.
- Do **not** add more adaptive seeds to the completed v1.0 screen.
- Do **not** tune LR, epochs, profile, evaluator, seed set, or controls inside a frozen scientific screen.
- Do **not** collapse `held-out domain performance` into `latent relation transfer`.
- Do **not** treat a complete truth table as automatically an identifying neighborhood.
- Do **not** call a contrast set identifying if plausible rival rules remain observationally equivalent.
- Do **not** treat global content equality as optimizer-visible geometry equality.
- Do **not** use post-hoc “probably a combination” as an escape after preregistered mechanisms fail to discriminate.
- Do **not** let the favorable +43 outrank the causal information in the -71.

## Process regressions
- Do **not** restore the predecessor SOP's mandatory method-stack pipeline. R3.1 corrected this: method-stack machinery is optional unless causally required or explicitly ordered.
- `METHOD_STACK_REFERENCE != MANDATORY_PIPELINE`.
- `ROLE_LABEL != AUTHORITY`.
- `MODE_LABEL != MUTATION_PERMISSION`.
- `RESEARCH_HEURISTIC != UNIVERSAL_MUST`.
- `FAILURE_SCAR != AUTOMATIC_BAN`.
- Do **not** claim execution from submission, completion from start, or registration from completion.
- A timeout/transport/control-plane failure is `UNKNOWN` until machine state is inspected.
- Do **not** conflate wrapper/control-plane failure with scientific execution failure.
- Evaluator `--adapter` must point to the actual adapter child, not its training parent.

## Architecture/continuity regressions
- Do **not** make chat memory the project state store.
- Do **not** let Live Shadow become a transcript.
- Do **not** let Design Thread Stream replace current-state readback.
- Do **not** silently rewrite sealed artifacts or remove contradictions from history.
- Do **not** make OS/runtime installation pull the full research archive, model caches, checkpoints, or reincarnation ZIPs.
