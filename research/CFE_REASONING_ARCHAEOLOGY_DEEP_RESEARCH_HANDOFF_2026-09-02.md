- **REJECTED / OVERREAD** — tempting interpretation explicitly demoted because evidence does not support it.

# 2. Current strongest synthesis

## 2.1 First layer — INFERRED

> **Reasoning can be modeled as constraint-preserving state transformation under changing evidence.**

This reframes “reasoning” away from chains of sentences and toward qualified state transitions:

- preserve still-valid constraints;
- alter tentative state;
- localize invalidation;
- retain unresolved uncertainty;
- let stronger evidence change qualification;
- maintain the governing objective.

## 2.2 Second layer — INFERRED

> **Capable reasoning may require changing the representation itself when the current coordinate system aliases states with different relevant consequences.**

Formal diagnostic:

`R(s1) = R(s2)`

while:

`relevant_consequence(s1) != relevant_consequence(s2)`

Then `R` is too coarse for the current objective.

This yields:

`REPRESENTATION FAILURE -> MISSING DISTINCTION -> COORDINATE REFINEMENT/REPLACEMENT -> RE-DERIVATION`

## 2.3 Third layer — INFERRED

> **Reasoning quality depends on maintaining the support topology of multiple still-possible states so changing evidence can selectively preserve, split, merge, invalidate, and refine them without premature global commitment or repeated full search.**

## 2.4 Fourth layer — INFERRED/HYPOTHESIZED

> **Useful reasoning control should allocate computation and observations according to expected discriminatory/decision value, not according to verbosity norms or prompt appearance.**

Compressed current candidate:

`CONSTRAINT-PRESERVING STATE TRANSFORMATION`
`+ REPRESENTATION-ADEQUACY MONITORING`
`+ SUPPORT/DEPENDENCY-AWARE POSSIBILITY MAINTENANCE`
`+ IDENTIFYING EVIDENCE ACQUISITION`
`+ VALUE-GUIDED CONTROL OF REASONING`

This is **not yet a CFE law and not an architecture**. It is a cross-substrate candidate structure strong enough to hostile-test directly.

# 3. The trace archaeology: what changed across time

The current archaeology has **67 registered source nodes**. A source-located worked-trace deck contains **15 actual trace specimens from 1959–2026**, represented in LBE as **15 trace nodes / 92 trace+event nodes / 164 typed edges**.

The important temporal story is not “symbolic -> neural -> better.” It is a migration of reasoning functions between explicit machinery, learned compression, generated traces, scaffolds, and partially internalized policies.

## 1959 — GPS

Visible topology:

`current state -> desired state -> salient difference -> relevant operator -> prerequisite subgoal -> transformation -> remaining difference`

Silent implications:
- reasoning is consequence-directed;
- operators are indexed by what they can change;
- subgoals arise when an operator is useful but not applicable;
- transformations preserve some features while changing others;
- object state and control/search state are separable.

Missing/not visible in the specimen:
- rich maintained alternative sets;
- support environments;
- learned representation change.

## 1977 — Version Spaces

`evidence-consistent hypothesis region -> new evidence -> remove inconsistent region -> minimally move boundaries -> preserve all survivors`

Silent implication:

> uncertainty can be represented as a structured region whose boundary moves under evidence.

Past evidence constrains legal future updates. History is active geometry, not transcript length.

## 1979 — Multiple Hypothesis Tracking

`ambiguous observation -> multiple associations -> weighted joint hypotheses -> later observation -> earlier association requalified -> prune/merge/factor`

Silent implications:
- later evidence reaches backward;
- ambiguity can stay open;
- equivalent-enough hypotheses can be merged for economy;
- independent subproblems can factor;
- false/missing observations belong in the model;
- time changes qualification, not merely sequence position.

## 1986 — ATMS

`datum -> minimal support environments -> incompatible contexts coexist -> contradiction -> nogood combination -> region excluded -> unaffected derivations survive elsewhere`

Silent implications:
- content and support are distinct state;
- contradiction need not erase everything;
- UNKNOWN is not negation;
- minimal supports compact many possible contexts;
- failure can generalize into a forbidden region;
- reason maintenance can be separated from domain inference.

## 1987 — GDE / diagnosis

`model/world mismatch -> competing minimal diagnoses -> choose measurement that separates candidates -> observe -> update candidate set -> repeat`

Silent implication:

> More evidence is not necessarily better evidence. Valuable evidence causes useful disagreement among surviving explanations.

This is an independent historical isomorph of CFE’s `RICH CONTRAST != IDENTIFYING CONTRAST` insight.

## 1987 — Soar trace-to-chunk

Successful deliberation is not preserved wholesale. Dependencies relevant to the successful result are traced and compiled.

Silent implication:

> experience is valuable because of the dependency structure it contains, not because every surface event deserves preservation.

This is a strong historical analogue of `STEAL INVARIANTS NOT ABSTRACTIONS`.

## 1993 — Dynamic Backtracking

`assign -> dead end -> inspect elimination explanations -> identify causal assignments -> undo causal support -> store elimination reason -> preserve unrelated work`

Silent implication:

> temporal recency is not causal responsibility.

Hence:

`ROLLBACK TO CAUSE, NOT CLOCK`

## 1996 — GRASP / conflict learning

`decision -> propagated implications -> conflict -> causal analysis -> learned constraint -> nonchronological backtrack`

Silent implication:

> the best product of a failed reasoning episode may be the reusable boundary it exposes, not the repaired answer.

## 2022 — Chain-of-Thought

CoT gives language models a radically flexible intermediate representation:

`problem -> generated intermediate semantic state -> later step consumes it -> answer`

Gain:
- domain-general intermediate vocabulary;
- dynamically generated abstractions;
- low engineering cost for new task representations.

Lost/hidden relative to older explicit systems:
- support environments;
- branch-local assumptions;
- explicit conflict regions;
- guaranteed local rollback;
- orthogonal verification authority.

Better historical reading:

> LLMs gained a flexible reasoning substrate while explicit reason-maintenance structure became weak, hidden, or implicit.

## 2022 — ReAct

`reason -> act/tool -> observation -> changed evidence state -> refined action/reasoning`

Silent implication:

> an action can change evidence state; a thought usually changes only internal state.

Reality/environment becomes an adjudicating channel.

## 2023 — Tree of Thoughts

ToT reconstructs:
- branch generation;
- frontier management;
- evaluation;
- pruning;
- backtracking/lookahead.

But:

`TREE OF TEXT != SUPPORT-AWARE MULTI-HYPOTHESIS FIELD`

It generally lacks compact minimal support, conflict learning, consequence-equivalence compression, and evidence-seeking discriminators.

## 2024 — Belief-R

`initial inference -> new premise -> retract or preserve earlier conclusion`

Observed benchmark problem:
- some models revise too little;
- others revise too much.

Silent implication:

> **revision sensitivity is not revision selectivity.**

The target is dependency-local revision.

## 2025 — DeepSeek-R1 visible trace

`path -> local distrust -> revisit earlier relation -> recompute -> revised path`

The phraseology is irrelevant. The structural event is an internally generated control-state change inside the same semantic stream.

Possible historical interpretation:
- some correction/search policy has been re-internalized;
- support/rollback structure remains far less explicit than ATMS/GRASP.

## 2026 — STALE

`old supported state -> later non-negating observation -> latent attribute/currentness update -> downstream old memory becomes inapplicable -> later retrieval/query must resist stale answer`

Silent implication:

`RETRIEVAL != CURRENTNESS RESOLUTION`

Knowledge update is not merely a new memory write. It requires dependency/currentness propagation.

## 2026 — CTRLS

`same setup -> different intermediate transition -> divergent downstream trajectory -> different terminal result`

Silent implication:

> ordered transitions between intermediate states are themselves a modeling target; a CoT is not just a bag/string of “helpful thoughts.”

# 4. Macro historical pattern — INFERRED

The strongest non-linear migration hypothesis is:

1. **Explicit external structure** — goals, branches, assumptions, conflicts, control hand-engineered.
2. **Specialized reason maintenance** — TMS/ATMS/diagnosis/SAT separate support/conflict from domain reasoning.
3. **Learned compression** — evaluation/search guidance moves into learned functions.
4. **Generative re-externalization** — LLM language becomes a flexible intermediate state surface.
5. **Scaffold reconstruction** — tools, ToT, verifiers, memories, process supervision re-add missing structure around models.
6. **Partial re-internalization** — reasoning training teaches correction/search/effort policies inside generated/latent behavior.
7. **Current seam** — flexible representation and explicit support-aware reason maintenance are still not cleanly unified.

Do not read this as inevitable progress. It is a **migration hypothesis**.

# 8. Representation-adequacy layer

## 8.1 Object failure vs representation failure

Object-level failure:

`R fixed; H1 fails; H2 under same R survives`

Representation-level failure:

`R cannot distinguish states whose relevant consequences differ`

This is a much deeper event than answer correction.

## 8.2 Meta-primitives

- **Representation adequacy monitor** — can current distinctions support a correct decision?
- **Missing-distinction detector** — persistent residual cannot be repaired by local hypothesis changes.
- **Granularity refinement** — split coarse state class into consequence-relevant subclasses.
- **Coordinate replacement** — move to a different representational form when refinement is insufficient.
- **Refinement with conservation** — preserve earned invariants while adding the necessary distinction.
- **Representation debt** — coarse abstraction works locally, accumulates exceptions, eventually becomes visibly inadequate.
- **Meta-currentness** — a representation can become stale relative to a changed regime/problem horizon.

## 8.3 Four planes of reasoning state

1. **Object state** — facts, quantities, observations, constraints.
2. **Hypothesis state** — candidate relations/plans/explanations.
3. **Representation state** — available entities/distinctions/coordinates.
4. **Control/authority state** — searching, verifying, deferring, revising, observing, admitting.

Do not flatten these merely because all appear as prose.
