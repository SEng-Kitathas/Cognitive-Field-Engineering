# GitHub Publication Policy

The GitHub repository is a continuity and collaboration surface, not the sole authority for machine execution.

Precedence on conflict:
1. live machine reality / sealed execution receipts;
2. current continuity state with readback;
3. current active project doctrine and scientific contracts;
4. historical artifacts;
5. prose summaries.

Every public scientific claim must carry an evidence ceiling. Historical files are preserved even when superseded. Corrections are additions/supersessions, not silent erasure.
