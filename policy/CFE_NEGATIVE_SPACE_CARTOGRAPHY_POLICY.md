# CFE Negative-Space Cartography Policy

Status: **ACTIVE OPERATOR-DIRECTED CONTROL POLICY — SOP-PEER PRIORITY**
Effective: 2026-08-31 23:39 Eastern Daylight Time
Authority: `state/doctrine_snapshot/ACTIVE_CFE_NEGATIVE_SPACE_CARTOGRAPHY_GOVERNANCE_2026-08-31.md`

## Required reads
Before selecting, designing, preregistering, extending, or interpreting a CFE experiment, read/reconcile:
1. active Commander's Intent binding/readback;
2. active Rahl SOP adoption;
3. active CFE Negative-Space Cartography Governance;
4. active machine-readable negative-space lattice;
5. active scientific current state / next steps.

## Required mutation
Any admitted scientific result that changes a cell, boundary, axis, or ranking SHALL cause a new cartography state or a verified update to the active cartography state in the same substantive reconciliation cycle.

## Selection gate
A new experiment SHALL NOT be frozen without a cartography binding containing:
- parent/neighbor cell;
- intended coordinate change;
- controlled coordinates;
- ambiguity reduced;
- adjacency/main-effect/interaction classification;
- expected result branches and how each modifies the map.

If this binding is missing, experiment selection is governance-incomplete.

## Evidence gate
Only admitted scientific evidence occupies a scientific cell.
- process crash -> execution lineage only;
- unpaired arm -> not an occupied paired-result cell;
- invalidated identity -> not scientific occupancy;
- provisional partial read -> may annotate active frontier but cannot close a cell.

## Ranking rule
Default ranking objective is **expected uncertainty reduction over the admissible CFE shape**, not probability of producing a positive result.

Tie-break pressure:
1. one-axis adjacency;
2. multiple characterized neighbors;
3. discriminates surviving mechanism hypotheses;
4. closes a known coverage hole;
5. enables a later interaction test;
6. lower implementation/confound burden.

## Laws
- `FIRST_CLASS CARTOGRAPHY != FIRST_CLASS CLAIM`
- `NEGATIVE SPACE != SPECULATIVE TRUTH`
- `UNMEASURED CELL != NEGATIVE CELL`
- `EXECUTION FAILURE != SCIENTIFIC OCCUPANCY`
- `PARTIAL RESULT != CLOSED CELL`
- `EXPERIMENT CHOICE SHOULD MAXIMIZE SHAPE INFORMATION, NOT HEADLINE POSITIVITY`
- `MAP UPDATE MUST FOLLOW EVIDENCE, NOT ANTICIPATE IT`
