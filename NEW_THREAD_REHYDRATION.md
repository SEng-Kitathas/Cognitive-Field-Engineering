# 1. Project identity and Commander’s Intent

## 1.1 What CFE is actually trying to discover

CFE is not “better curriculum ordering,” “group related examples,” “long-context training,” or “efficiently teach a known rule.” The governing thesis is that **the developmental structure of experience itself is an engineering medium**.

Core operator phrasing preserved across the project:

> **ENGINEER THE TERRAIN, NOT THE ANIMAL.**

> **SHAPE THE FIELD != PRESCRIBE THE ORGANISM.**

The target is to engineer lawful developmental terrain so useful cognition has reason to **emerge, compose, transfer, calibrate, revise, and be appropriately recruited**, without prescribing the learner’s internal ontology.

The stronger current Commander’s Intent is:

> **We are not merely trying to discover the right developmental geometry. We are trying to reconstruct the topology of constraints governing developmental geometry, while simultaneously hostile-engineering the coordinate system used to describe that topology.**

Operational consequence: the project must map both **positive structure and negative space**. Every apparent axis/coordinate is suspect until hostile controls show it is independently manipulable and consequence-bearing.

## 1.2 Identifying CFE vs developmental CFE

Do not collapse these:
- **Identifying CFE:** curator knows a target relation and engineers a support basis that distinguishes it from plausible rivals.
- **Developmental CFE:** curator knows lawful ecology/consequence structure but does **not** prescribe the internal representation/strategy the learner must form.

A designed environment is not a designed learner ontology. Curator-side field coordinates are instruments, not learner truth.

## 1.3 Global epistemic laws that must survive thread transition

- **Observed consequence outranks intent, labels, docs, model confidence, evaluator expectation, and prior narrative.**
- **STEAL INVARIANTS, NOT ABSTRACTIONS.** Donors are quarries, not authorities.
- **Composition-first:** test whether existing parts compose before inventing new primitives.
- **UNKNOWN is a legitimate state.** Do not force closure when evidence does not discriminate.
- **Evidence inherits; confidence does not.** Confidence is re-earned each pass.
- **Research success does not auto-promote doctrine, architecture, training data, or execution authorization.**
- **Tool output != qualified consequence.** Submitted != started != completed != registered.
- **Execution failure is not scientific negative evidence.** A failed arm does not occupy a negative causal cell.
- **Source geometry != learner-visible geometry != optimizer-visible update-field geometry.**
- **Same global atom multiset != same developmental field.**
- **Rich/coherent support != identifying support.**
- **Long context != long-horizon cognition.** Consequential history matters, not mere token span.

- hidden state assumptions;

- authority transitions;
- unresolved seams;
- what gets preserved vs rolled back;

# 10. Engineering scars from this thread that future work must remember

1. **JSONL parser scar:** Python `str.splitlines()` split valid JSON strings containing Unicode line separators and falsely appeared to corrupt the v2 corpus. Correct JSONL reader must iterate on actual LF record delimiters.
2. **Jargon scanner scar:** naive substring scanning flagged `ATMS` inside ordinary “ATMs” and `CFE` inside URLs/hashes/identifiers. Semantic phrase scanning replaced it. Do not resurrect naive acronym filters.
3. **Synthetic gap-filler scar:** hostile review caught grammar artifacts, `.capitalize()` case corruption (`B2 -> b2`), tied discriminator comparing a check to itself, machiney placeholders, and awkward articles. Generator was fixed before V1R4 freeze.
4. **Repeated prompt != duplicate trajectory:** 32 exact prompt groups had different trajectories. Alternates were segregated, not blindly deduped or ranked by length.
5. **License scar:** “mixed source” metadata does not automatically imply unresolved row license; Nemotron Agentic v2 was resolved from exact pinned dataset-card governance, preserving provenance rather than guessing.
6. **Eval registry access scar:** gated GPQA/HLE were not mirrored around access controls; operator accepted terms and direct authenticated access was used.
7. **LCB transfer scar:** full benchmark source would waste ~4.3 GB mostly on private tests; HTTP Range + Parquet column projection obtained only protected prompt columns and cross-verified against direct official overlap.
8. **BFCL scar:** `format_sensitivity.json` is a selection list of IDs, not question JSONL. Parse errors from treating it as prompt data were a tooling classification error, not missing coverage.
9. **Fuzzy-scanner scar:** lexical high scores can be caused by short generic phrases embedded in long unrelated prompts. Manual structural adjudication is mandatory; scanner score is not automatic truth.
10. **Do not count execution failures as scientific sign.** This has already caused enough pressure in DD1/DD2 recovery work.
